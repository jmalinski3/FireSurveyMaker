Context: I'm building a UKG Telestaff Cloud roster scraper for the City of
Naperville Fire Department. Here's the full picture so you're caught up.

WHAT IT IS
- A Python + Playwright script that logs into UKG Telestaff Cloud, scrapes the
  daily fire-department roster, and exports it to CSV. Goal: publish upcoming
  shifts to our member website so people can plan ahead.

HOW IT WORKS
- Auth: secrets (username, password, TOTP seed) are in the OS keyring under
  service "ukg-roster". The script generates TOTP codes itself (pyotp), so MFA
  is fully automated/headless. A persistent browser profile (./profile) holds
  Telestaff's 7-day "remember this device" cookie, so MFA is rarely triggered.
- Login flow is 3-step Telestaff: /telestaff/login (user+pass) ->
  /telestaff/mfa (click "Continue", #continueButton) ->
  /telestaff/mfa/totpValidation (enter code #mfaVerificationCode, check
  #mfaTrustDeviceCheck, submit #registerButton). An intermittent
  /telestaff/checkContactLog interstitial may need dismissing (dismiss_selectors
  in config; currently a placeholder "button.close", not yet observed).
- Multi-day: the roster date is encoded in the URL path as d[YYYYMMDD]. Config
  has roster_url_template with a {date} placeholder; the script loops over today
  .. today+days_ahead (default 3 => 4 CSVs). It verifies the scraped page's date
  matches the requested date before writing.
- The roster is NOT an HTML table — it's a nested treegrid (#rosterFixedContent:
  date > battalion > shift > station > unit > li.idPosition). Extraction is a
  page.evaluate() DOM walk producing 14 columns: date, shift, station, unit,
  position, name, person_id, job_title, work_code, status, record_type, start,
  end, duration. IMPORTANT: those <li> rows have no layout box, so Playwright
  visibility checks fail on them — readiness is checked with state="attached"
  (is_present helper), not "visible".
- Output: output/roster_<date>.csv. Writes are CHANGE-AWARE (only rewrite a
  day's file when content differs). Retention deletes CSVs older than
  retain_past_days (default 1 => keep yesterday onward).
